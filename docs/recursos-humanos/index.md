# Nómina y recursos humanos

<p class="tambien-se-busca">También se busca como: empleados, nómina, liquidar nómina, vacaciones, incapacidades, prestaciones, seguridad social, nómina electrónica.</p>

## ¿Qué hay en el menú Nómina?

| Grupo | Opción | Para qué sirve |
|---|---|---|
| Personal | **Cargos** | Cargos de tu empresa. |
| | **Empleados** | Ficha de cada empleado, con sus datos de seguridad social. Se pueden importar. |
| Nómina | **Dashboard** | Resumen de la nómina. |
| | **Incapacidades**, **Vacaciones**, **Novedades** | Registrar lo que afecta el pago del período. |
| | **Período Nómina** | Crear y liquidar los períodos de pago. |
| | **Pagos Nómina**, **Nóminas Pagadas** | Pagar la nómina y consultar lo pagado. |
| | **Provisiones** | Provisiones de prestaciones sociales. |
| | **Liquidaciones** | Liquidación de empleados que se retiran. |
| | **Nómina Electrónica** | Envío de la nómina a la DIAN. |
| Configuración | **Configuración Nómina**, **Cuentas Contables de Nómina** | Parámetros y cuentas contables. |
