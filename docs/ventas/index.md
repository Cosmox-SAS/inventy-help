# Ventas

Usa el menú **Ventas** para facturar a tus clientes desde la oficina (con más detalle que en el POS), manejar ventas a crédito y registrar devoluciones.

!!! tip "¿POS o Factura?"
    - **POS** (<span class="ruta">Ventas › POS</span>): ventas rápidas de mostrador, con caja abierta. Ver [Punto de venta](../pos/index.md).
    - **Facturas** (<span class="ruta">Ventas › Facturas</span>): ventas de oficina, a crédito, con fecha, centro de costo, retenciones y observaciones.

## Estados de una factura de venta

| Estado | Qué significa | ¿Se puede editar? |
|---|---|---|
| **Borrador** | Guardada pero no confirmada. No afecta inventario ni contabilidad. | Sí |
| **Validada** | Confirmada. Afecta inventario, cartera y contabilidad. | No |
| **Pagada** | Validada y sin saldo pendiente. | No |
| **Anulada** | Cancelada con un motivo. | No |
