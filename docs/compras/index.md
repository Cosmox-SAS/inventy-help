# Compras

Usa el menú **Compras** para registrar lo que le compras a tus proveedores. Al validar una compra, Inventy **aumenta tu inventario**, registra la **cuenta por pagar** y genera la contabilidad.

## Guías disponibles

- [¿Cómo registro una factura de compra?](registrar-factura-compra.md)
- [¿Cómo emito un documento soporte electrónico?](../facturacion-electronica/documento-soporte.md) (compras a proveedores no obligados a facturar)

## ¿Qué hay en el menú Compras?

| Opción | Para qué sirve |
|---|---|
| **Dashboard** | Resumen de tus compras. |
| **Órdenes de Compra** | Pedidos a proveedores antes de recibir la mercancía. |
| **Facturas** | Facturas de proveedores (con o sin orden de compra). |
| **Legalización de gastos** | Agrupa varias facturas de servicios pendientes de legalizar (ej. gastos de caja menor). |
| **Pendientes** | Órdenes de compra que aún no se han facturado completamente. |
| **Devoluciones** | Mercancía que le devuelves al proveedor. |
| **Proveedores** | Tus proveedores. |
| **Reportes › Compras** | Reporte de compras. |

!!! tip "¿Cómo registro un gasto?"
    - Si el gasto tiene **factura del proveedor** (arriendo, servicios, papelería): regístralo como una [factura de compra](registrar-factura-compra.md).
    - Si son **varias facturas pequeñas de servicios** que se pagaron con un mismo dinero: usa **Legalización de gastos**.
    - Para registrar el **pago** al proveedor: usa [Egresos](../finanzas/registrar-egreso.md).
