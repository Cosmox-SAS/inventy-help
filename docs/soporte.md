# Contactar a soporte

<p class="tambien-se-busca">También se busca como: ayuda, asesor, mesa de ayuda, reportar un error, hablar con alguien.</p>

## Antes de escribirnos

1. Busca tu duda en el buscador de este Centro de Ayuda.
2. Revisa las [Soluciones rápidas](soluciones-rapidas/index.md).
3. Si trabajas con otras personas, pregunta al **administrador de tu empresa**: muchos problemas se resuelven con un permiso o un módulo que él puede activar.

## Qué información enviar

Incluir estos datos nos permite resolver tu caso sin pedirte más información:

- [x] **Nombre de tu empresa** tal como aparece en Inventy.
- [x] **Tu correo de acceso** (el del usuario que tiene el problema).
- [x] **Qué estabas haciendo**: menú y pantalla (por ejemplo, *Ventas › Facturas*).
- [x] **Número del documento** involucrado (factura, devolución, ajuste, cierre de caja…).
- [x] **Fecha y hora aproximada** en que ocurrió.
- [x] **Captura de pantalla** del mensaje de error completo.
- [x] Si ocurre **siempre** o solo a veces, y si le pasa a otros usuarios.

!!! danger "Nunca compartas"
    Tu **contraseña**, tu **PIN de autorización**, códigos de verificación ni datos completos de tarjetas. El equipo de Inventy **nunca** te los pedirá.
