# Restaurante

<p class="tambien-se-busca">También se busca como: mesas, comandas, cocina, domicilios, propinas, meseros, pedidos, prefactura.</p>

El módulo **Restaurante** adapta el POS a la operación de restaurantes, cafeterías y comidas rápidas.

## ¿Qué hay en el menú Restaurante?

| Grupo | Opción | Para qué sirve |
|---|---|---|
| Restaurante | **Pedidos** | Pedidos en curso. |
| | **Tablero de pedidos** | Vista de los pedidos del POS por estado. |
| | **Estaciones de preparación** | Cocina, bar, etc. Cada producto se envía a su estación. |
| | **Mesas** | Distribución visual de las mesas del local. |
| Domicilios | **Repartidores**, **Liquidación** | Domiciliarios y liquidación de sus entregas. Ver [guía](domicilios.md). |
| Propinas | **Colaboradores**, **Liquidación**, **Reporte** | Reparto de propinas al equipo. |

## Opciones de configuración

En <span class="ruta">Configuración › Módulos › Restaurante</span> puedes activar:

- **Habilitar pedidos a la mesa** y, una vez activo, **Permitir varias cuentas por mesa** ([guía](varias-cuentas-mesa.md)).
- **Habilitar pedidos a domicilio**, **Valor del domicilio obligatorio** y **Pagar el domicilio al repartidor al instante**.
- **Porcentaje de propina** sugerido y el texto de advertencia de la prefactura.
- **Mostrar desglose en la tirilla**.

## En el POS

Con el módulo activo, el POS permite elegir el **tipo de pedido** (por ejemplo, **A la mesa**), seleccionar la mesa, **Realizar pedido**, **Generar comanda para cocina** y cobrar con **Cobrar pedido**.
