# ¿Cómo activo o desactivo módulos?

<p class="tambien-se-busca">También se busca como: habilitar módulo, activar opción, configuración de módulos, encender restaurante, activar lotes, activar promociones, stock negativo.</p>

## ¿Para qué sirve?

Inventy se adapta a tu negocio. En **Configuración de módulos** decides qué partes usa tu empresa y cómo se comportan (por ejemplo, si el POS permite descuentos por producto o si el inventario puede quedar en negativo).

## Antes de comenzar

- [ ] Ser **administrador** o tener permiso de configuración.
- [ ] Saber que solo puedes activar los módulos **incluidos en tu plan**. Los demás aparecen con el aviso *“Este módulo está bloqueado por tu suscripción”*.

## Paso a paso

**Paso 1.** Ingresa al menú <span class="ruta">Configuración › Módulos</span>. Verás **Configuración de módulos**: a la izquierda la lista de módulos y a la derecha sus opciones.

**Paso 2.** Selecciona el módulo que quieres configurar.

**Paso 3.** Usa el interruptor **Habilitar módulo** / **Deshabilitar módulo** para encenderlo o apagarlo.

**Paso 4.** Revisa las opciones del módulo y activa las que necesites.

## Opciones que más se consultan

Lista completa, con qué debe estar activo para que aparezca cada opción: [Todas las opciones de Módulos](opciones-modulos.md).


| Módulo | Opción | Qué hace |
|---|---|---|
| Ventas | **Permitir ventas de contado sin sesión de caja** | Permite vender en efectivo sin tener una caja abierta. |
| Ventas | **Descuento manual por producto en el POS** | El cajero puede aplicar un descuento de 0 % a 99 % a cada producto. |
| Ventas | **Exigir vendedor en el POS** | Obliga a elegir un vendedor antes de facturar. |
| Ventas | **Habilitar promociones** / **Habilitar listas de precios** | Muestra los menús Promociones y Listas de precios. |
| Ventas | **Crédito ilimitado para clientes** | Todos los clientes pueden comprar a crédito sin límite de cupo. |
| Ventas | **Requerir autorización para cupo de crédito adicional** | Pide el PIN de un supervisor cuando una venta supera el cupo del cliente. |
| Ventas | **Mostrar el PDF de la factura en el POS** | Abre el PDF en lugar de imprimir la tirilla. |
| Ventas | **Habilitar remisiones de venta** | Permite entregar mercancía con remisión y facturarla después. |
| Inventario | **Permitir stock negativo** | Permite vender o sacar productos aunque no haya existencias. |
| Inventario | Seriales, **Lotes y vencimientos**, Presentaciones, **Kits de venta**, **Atributos y variantes**, **Visibilidad por sede** | Activa esas funciones en los productos. |
| Fiscal | **Emitir documento electrónico automáticamente** | Al validar una factura o nota, se envía sola a la DIAN. |
| Restaurante | Pedidos a la mesa, a domicilio, propinas | Configura la operación del restaurante. |

## Resultado esperado

Los menús y opciones del módulo aparecen (o desaparecen) para los usuarios con permiso. Si un usuario tenía la pantalla abierta, puede necesitar **recargar la página**.

## Problemas frecuentes

??? question "“Este módulo está bloqueado por tu suscripción”"
    El módulo no está incluido en tu plan. Puedes revisar los planes en <span class="ruta">Configuración › Suscripción</span> o usar el botón **Mejorar plan**.

??? question "Activé el módulo pero otro usuario no lo ve"
    Además de activar el módulo, el **rol** del usuario debe tener los permisos de ese módulo. Revisa [Roles y permisos](roles-y-permisos.md).
